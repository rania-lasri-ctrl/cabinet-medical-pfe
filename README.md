# Cabinet Médical

## Présentation

Application web de gestion d'un cabinet médical développée dans le cadre
d'un Projet de Fin d'Études.

## Fonctionnalités

- Authentification des utilisateurs
- Gestion des patients
- Gestion des rendez-vous
- Gestion des prescriptions
- Gestion des factures
- Espace patient
- Paiement en ligne avec Stripe Test Mode
- Gestion des statuts des rendez-vous

## Technologies

- PHP
- MySQL
- PDO
- HTML5
- JavaScript
- Tailwind CSS
- Stripe Checkout
- XAMPP

## Installation

1. Installer XAMPP.
2. Copier le projet dans `htdocs`.
3. Créer la base de données `cabinet_db`.
4. Importer le fichier SQL.
5. Configurer la connexion à la base de données.
6. Lancer Apache et MySQL.
7. Accéder à l'application via :

http://localhost/cabinet_pfe
